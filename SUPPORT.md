# MoneyUp Support

MoneyUp is currently a Founders Beta. The fastest support channel for an
installed TestFlight build is **Send Beta Feedback** in the TestFlight app.
General reproducible defects can also be reported at
<https://github.com/LaiWenKang/MoneyUp/issues>.

A public direct-contact mailbox has not yet been published. Before MoneyUp is
submitted to the public App Store, a monitored support email must be added to
this page. Until then, this page supports only the invited founders beta.

Before reporting a problem:

1. Confirm that TestFlight shows the newest available build.
2. Note the MoneyUp version shown under **Assets → Data and privacy**.
3. Reproduce the issue once with a small sample amount if it is safe to do so.
4. Do not reinstall or erase data when the issue concerns missing or
   inaccessible records.

Include the following:

- MoneyUp version and build number;
- iPhone model and iOS version;
- app language (English or Simplified Chinese);
- exact steps, expected result, and actual result;
- whether the problem happens every time;
- a screenshot only after hiding balances, names, account numbers, receipts,
  addresses, and other private information.

Never post financial exports, database files, encryption keys, provisioning
profiles, Apple credentials, or unredacted screenshots in a public issue.

For a security vulnerability, use GitHub private vulnerability reporting when
available instead of a public issue. For an Apple Developer enrollment,
signing, TestFlight processing, or App Review problem, use Apple Developer
Support because MoneyUp cannot access or change Apple's account status.

## Severity used during beta

- **P0:** data loss, privacy exposure, unrecoverable launch failure, or incorrect
  ledger totals. Stop testing and report immediately.
- **P1:** crash, blocked core workflow, or materially wrong budget/report.
- **P2:** confusing behavior with a safe workaround.
- **P3:** visual polish, copy, or enhancement request.

# MoneyUp 支持（简体中文）

MoneyUp 目前处于首轮测试阶段。对于已安装的 TestFlight 版本，最快的支持方式
是在 TestFlight 应用中使用“发送 Beta 版反馈”。可稳定复现的一般问题也可提交
至 <https://github.com/LaiWenKang/MoneyUp/issues>。

目前尚未公布对外联系邮箱。MoneyUp 提交公开 App Store 审核前，必须在此页面
加入有人定期查看的支持邮箱；在此之前，本页面仅服务受邀的首轮测试。

提交问题前：

1. 确认 TestFlight 显示的是最新可用版本。
2. 记录 **资产 → 数据与隐私** 中显示的 MoneyUp 版本与构建号。
3. 在安全的情况下，用小额样例再次复现。
4. 如果问题涉及数据丢失或无法访问，请勿重新安装应用或抹掉数据。

请提供 MoneyUp 版本与构建号、iPhone 型号、iOS 版本、应用语言、准确操作步骤、
预期结果、实际结果，以及问题是否每次发生。只有在遮盖余额、姓名、账号、收据、
地址和其他隐私信息后才附加截图。

不要在公开问题中发布财务导出文件、数据库、加密密钥、描述文件、Apple 凭据
或未遮盖的截图。安全漏洞应在可用时使用 GitHub 私密漏洞报告。Apple Developer
注册、签名、TestFlight 处理或 App Review 问题应联系 Apple Developer Support。

测试期间的严重程度：P0 为数据丢失、隐私泄露、无法启动或账本合计错误；P1 为
崩溃、核心流程受阻或预算/报表严重错误；P2 为有安全替代方法的困惑行为；P3 为
视觉、文字或增强建议。
